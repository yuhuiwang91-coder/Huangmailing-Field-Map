# Huangmailing Field Map

黄麦岭野外地质地图独立项目。

## 当前内容
- 高德 JS API 手机网页框架
- 普通图 / 卫星图切换
- GPS 定位
- HML 野外样点记录与 CSV / GeoJSON 导出
- 黄麦岭 15 km 地质属性查询索引
- H5001 大悟幅、H5007 黄陂幅栅格图层配置
- GitHub Pages 兼容文件（.nojekyll / manifest）

## 原始地质图资源
网页预期以下文件：
- `data/raster/H5001_native_GCJ02_TIF6000.png`
- `data/raster/H5007_native_GCJ02.png`
- `data/legend/H5001_legend_exact.png`
- `data/legend/H5007_legend_exact.png`

这些文件来自 MapGIS 原始图式，用于保留地层配色、侵入岩配色、填充花纹、断层、产状和文字标注。
